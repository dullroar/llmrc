# Behavioral layer stays separate from context

**Decision.** LLMRC separates stable behavioral preferences from domain, project, task, and conversation context, so a personal interaction contract does not become a dump of project-specific facts. Personal identity narrative is kept separate from the stable behavioral layer.

**Boundary.** LLMRC guides behavior; it does not replace repository instructions, domain policies, or task-specific requirements.
