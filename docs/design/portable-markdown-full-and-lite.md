# Portable Markdown in full and lite forms

**Decision.** Plain Markdown lets the same material travel across chat interfaces, coding agents, local models, and API workflows. A full form supports richer co-thinking; the lite form is sized for coding-agent context budgets. Explicit epistemic labeling, auditability, and reusable artifacts are favored over tool-vendor-specific behavior.

**Contradicted by.** Vendor-specific syntax, or growth of the lite form beyond a coding-agent context budget.
